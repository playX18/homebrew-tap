# homebrew-tap

Homebrew formulae for [CapyScheme](https://github.com/playX18/capyscheme).

```sh
brew tap playX18/tap
brew install capyscheme          # stable: capy, capyc
brew install capyscheme-nightly  # nightly: capy-nightly, capyc-nightly
```

Formulae are updated automatically by the CapyScheme release and nightly workflows.
